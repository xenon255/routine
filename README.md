# Routine

Minimalistische Progressive Web App zur Verwaltung täglicher, wöchentlicher und monatlicher Gewohnheiten.

## Aktueller Stand: v0.2.1

- Heute-Ansicht mit Wochenleiste
- Gruppen und Gewohnheiten
- tägliche, wöchentliche und monatliche Wiederholungen
- Kalender mit Fortschrittsringen
- Hell-, Dunkel- und Systemmodus
- lokale Speicherung im Browser
- Export und Import
- Offline-Unterstützung

## Veröffentlichung

Die Web-App wird über GitHub Pages direkt aus dem Hauptverzeichnis des Branches `main` veröffentlicht.

GitHub Pages:

1. Repository-Einstellungen öffnen
2. `Pages` auswählen
3. Quelle: `Deploy from a branch`
4. Branch: `main`
5. Ordner: `/ (root)`
6. Speichern

## Datenschutz

Die Gewohnheitsdaten werden ausschließlich lokal im Browser des jeweiligen Geräts gespeichert. Im Repository liegen nur Programmdateien, keine persönlichen Gewohnheitsdaten.

## Versionsschema

- `0.x`: Entwicklung und Tests
- `1.0`: erste stabile persönliche Version
